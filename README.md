# 🧠 NLP Query Engine for Employee Data

A full-stack AI-powered application that lets you query your employee database using **natural language** — no SQL knowledge required.  
It can dynamically understand your database schema and even fetch answers from uploaded documents (like resumes or PDFs).

---

## 🚀 Core Features

- **Dynamic Schema Discovery** – Automatically identifies tables, columns, and relationships in your database.  
- **Natural Language Queries** – Converts plain English questions into SQL queries.  
- **Hybrid Search** – Fetches answers from both structured (SQL) and unstructured (documents) data.  
- **Document Upload** – Supports PDF, DOCX, TXT, and CSV.  
- **Performance Optimized** – Includes caching, async processing, and FAISS-based vector search.

---

## 🧰 Tech Stack

- **Backend** – FastAPI (Python)  
- **Frontend** – React (Vite)  
- **Database** – PostgreSQL  
- **LLM Integration** – Groq API for NL-to-SQL  
- **Embeddings** – Sentence-Transformers  
- **Vector Store** – FAISS  
- **Cache** – Redis
